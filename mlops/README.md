# Iris Flower Classification ML API

This project implements a simple ML model for Iris flower classification with a FastAPI prediction endpoint.

## Project Structure

- `app.py`: FastAPI application with prediction endpoint
- `train_model.py`: Script to train and save the Iris classification model
- `model.pkl`: Trained model file (generated by running train_model.py)
- `requirements.txt`: Package dependencies
- `.github/workflows/ci.yml`: CI workflow for GitHub Actions

## Setup

1. Create a virtual environment (optional):
   ```
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

3. Train the model:
   ```
   python train_model.py
   ```

4. Run the API:
   ```
   uvicorn app:app --reload
   ```

## API Usage

The API will be available at `http://localhost:8000`.

### Endpoints

- `GET /`: Root endpoint returning API status
- `GET /health`: Health check endpoint
- `POST /predict`: Prediction endpoint

### Making Predictions

You can make a prediction request to the API using curl:

```bash
curl -X POST "http://localhost:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "sepal_length": 5.1,
    "sepal_width": 3.5,
    "petal_length": 1.4,
    "petal_width": 0.2
  }'
```

Or using the interactive Swagger UI at `http://localhost:8000/docs`.

## CI Workflow

The CI pipeline:
1. Sets up Python
2. Installs dependencies
3. Trains the model
4. Verifies the model loads correctly
5. Verifies the FastAPI application starts
6. Uploads the model as an artifact
